# Research Seminar Series Uploads

Create or use a year folder, then upload files by type.

Recommended structure:

`2026/presentations/`

`2026/registration-forms/`

`2026/videos/`

`2026/images/`

After uploading a file, reference it in `src/pages/SeminarSeries.tsx`.

Example:

`presentationUrl: "/uploads/research/seminar-series/2026/presentations/my-seminar.pdf"`

For videos, prefer an external video URL for large files.
