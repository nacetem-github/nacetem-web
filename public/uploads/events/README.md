# Event Uploads

Use these folders for event files:

- `flyers/<year>/<event-slug>/`
- `source-documents/<year>/<event-slug>/`
- `images/`
- `gallery/<event-slug>/`
- `registration-forms/`
- `videos/`

Gallery folders should use event-style slugs that match the entries in `src/pages/News.tsx`.

For upcoming events, upload the flyer and a source document with:

- event title
- date and time
- location or virtual platform
- registration or meeting link, where applicable
- short event description
- contact person or department, where applicable
