# Event Source Documents

Upload Word documents, text files, or PDFs containing upcoming event details here.

Use one folder per year and event slug.

Include:

- event title
- date and time
- location or virtual platform
- registration or meeting link, where applicable
- short event description
- contact person or department, where applicable

Example:

`public/uploads/events/source-documents/2026/national-innovation-summit/details.docx`
