# PSR Chapter 2 Form Generator

Generated files:

- `chapter2_question_bank.csv`: upload this to Google Sheets and rename the tab to `Question Bank`.
- `chapter2_split_plan.csv`: review the generated smaller Form groups.
- `chapter2_split_plan.json`: machine-readable split plan.
- `chapter2_validation_report.json`: validation summary from the source Excel files.
- `CreateChapter2Forms.gs`: Apps Script that creates the Google Forms quizzes.

Review the split plan and validation report before running the Apps Script.
